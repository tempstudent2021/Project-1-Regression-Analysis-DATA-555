For this regression analysis project I will be using the "Dummy Data HSS" marketing dataset. The characteristics of the dataset are that it has 4,572 rows; each row records a campaign's TV, radio and social media budgets, the type of influencer used (Mega, Macro, Micro or Nano), and the resulting `Sales`. Three predictors are numeric, `Influencer` is categorical, and `Sales` is the continuous target. The cleaning steps I will need to take to prepare the data for analysis are to count missing values and duplicates, confirm the `Influencer` labels are consistent, and flag outliers; the few rows with a missing value will be dropped only if that leaves the means and spreads unchanged. The initial visualizations that will help me understand the relationships between the variables will be histograms of every variable, scatterplots of `Sales` against each budget, a boxplot of `Sales` by `Influencer` type, and a correlation heatmap. The type of regression model I plan to use is a multiple linear regression (OLS) model because the target variable is continuous and the main predictors are numeric, and the scatterplots will confirm whether the relationships are linear. I will fit models of increasing complexity (TV only, then adding Radio, Social Media and Influencer dummy variables) and compare them on a held-out 20% test set using R², RMSE and MAE, plus 5-fold cross-validation. Advertising budgets often rise together, so I will check multicollinearity with correlations and variance inflation factors (VIF) and use nested F-tests to decide whether extra predictors are worth keeping. Finally, I will inspect residual plots for linearity, constant variance and normality.
